Mettre à jour écoles, intervenants et types

À utiliser après une mise à jour du site qui change la liste des écoles, des intervenants ou des types d'intervention (le code source, js/seed-data.js) — sinon le repo privé de données reste sur l'ancienne liste et les nouveautés n'apparaissent pas dans les menus. Connectez d'abord le repo via ⚙ Données ci-dessus si ce n'est pas déjà fait.

Écoles et intervenants sont remplacés par la version actuelle du code : tout ajout ou changement fait uniquement depuis l'application (écoles de référence, nouvel intervenant...) sera perdu. Les types d'intervention, eux, sont fusionnés : les types déjà utilisés et les types personnalisés créés en cours d'usage sont conservés, seuls les types explicitement retirés de la typologie officielle (ex. Instruction à domicile, Agrément) sont supprimés de la liste.
