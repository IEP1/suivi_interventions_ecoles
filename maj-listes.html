Mettre à jour écoles, intervenants et types

À utiliser après une mise à jour du site qui change la liste des écoles, des intervenants ou des types d'intervention (le code source, js/seed-data.js) — sinon le repo privé de données reste sur l'ancienne liste et les nouveautés n'apparaissent pas dans les menus.

Les écoles sont remplacées par la version actuelle du code : tout ajout ou changement fait uniquement depuis l'application (écoles de référence...) sera perdu. Les intervenants et les types d'intervention, eux, sont fusionnés : un intervenant ou un type déjà présent dans votre repo (nom personnalisé compris) n'est jamais écrasé — seuls les nouveaux (absents du repo) sont ajoutés depuis le code, et seuls les types explicitement retirés de la typologie officielle (ex. Instruction à domicile, Agrément) sont supprimés. 


  


  

    
Nettoyer les types personnalisés en double

    

      Toute action personnalisée saisie une fois (libellé libre) reste ensuite proposée dans
      « Actions personnalisées » — avec le temps, certaines finissent par faire doublon avec un
      type officiel (ex. une ancienne « Conseil des maîtres » alors que le type « Instance d'école »
      couvre déjà ce cas) ou avec le champ Origine (ex. « Intervention à la demande de l'IEN »).
      Cet outil liste les types personnalisés actuellement enregistrés dans le repo de données et
      permet de les fusionner vers un type officiel (les interventions déjà saisies sont
      automatiquement réaffectées) ou de les supprimer s'ils ne sont utilisés par aucune
      intervention.
    

    

    

      
    

    

    

  


  

    
Réaffecter d'anciens types déjà enregistrés

    

      Corrige, dans les interventions déjà enregistrées sur GitHub, les typeId devenus obsolètes.
      Sans risque à relancer plusieurs fois : une intervention déjà corrigée n'est pas retouchée.
